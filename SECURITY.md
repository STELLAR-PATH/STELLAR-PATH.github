# Security Policy

## Supported Versions
Only the latest release of StellarPath tooling is actively supported for security patches.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability within any STELLAR-PATH project, please do not file a public issue. 

Report vulnerabilities directly to the maintainers via GitHub private vulnerability reporting on the respective repository or contact the lead maintainer. Reports are investigated promptly and coordinated disclosures are made available alongside patched releases.
